# Этап 4: UI и доступность — 29 июля 2026

## Результат

Ключевые flows (`dashboard`, users CRUD, forms, settings, auth и overlays)
проверяются в ограниченном WCAG 2.2 AA scope. Общий dialog primitive управляет
фокусом и клавиатурой, поля используют единый контракт label/error, а цвета
основного UI зависят от semantic tokens.

## Изменения

- `UserFormModal` и `ConfirmModal` переведены на общий portal-based `Dialog`.
- `Dialog` предоставляет `dialog`/`alertdialog`, `aria-modal`, связи
  title/description, Escape, focus trap, initial/restore focus, scroll lock и
  настраиваемое закрытие по overlay.
- `FormField` централизует `label`, `aria-invalid`, `aria-describedby` и
  объявление ошибок через `role="alert"`.
- Labels и error associations добавлены в users, advanced forms, settings и
  auth; charts и page-size select получили accessible names.
- Dropdown/account overlays закрываются по Escape и внешнему pointer event с
  возвратом фокуса на trigger.
- Локальные core-цвета заменены semantic tokens; отдельные light/dark значения
  контрастных `danger`, `success`, `info`, `warning` проверены axe.
- Добавлен глобальный `prefers-reduced-motion` fallback.
- Таблицы на узком viewport используют горизонтальный scroll с минимальной
  читаемой шириной вместо посимвольного переноса ячеек.

## Инвентаризация patterns

| Pattern                             |                      Реальные применения | Решение                                                                      |
| ----------------------------------- | ---------------------------------------: | ---------------------------------------------------------------------------- |
| Page shell                          |        dashboard, users, forms, settings | Оставлен `PageLayout`.                                                       |
| Content card/section                | dashboard widgets, users table, settings | Оставлены `section-container` и `form-section`; новый card wrapper не нужен. |
| Label + control + description/error |       users modal, forms, settings, auth | Выделен `FormField`, так как pattern повторяется более двух раз.             |
| Modal overlay                       |    user create/edit, delete confirmation | Сведён к одному `Dialog`; feature wrappers сохранили продуктовые действия.   |
| Table toolbar/pagination            |                      users, recent users | Сохранены существующие data-table primitives.                                |

## Автоматические проверки

- Jest + Testing Library: focus trap, Escape, focus restore, safe initial focus,
  outside interaction, labels и error associations.
- `jest-axe`: `Dialog` и `UserFormModal`.
- Playwright + axe: пять ключевых маршрутов.
- Visual smoke: Chromium и WebKit, `1280×800` и `390×844`, light и dark —
  полный набор из 40 baseline screenshots.
- CI: отдельный browser accessibility job для Chromium и WebKit.

Команды:

```bash
npm run test:e2e:a11y
npm run test:e2e:visual
npm run test:e2e:visual:update
```

Darwin baselines находятся в
`tests/e2e/visual.spec.ts-snapshots`. Для другой OS нужно создать её
platform-specific snapshots командой обновления; CI запускает axe smoke и не
сравнивает macOS rasterization с Linux.
